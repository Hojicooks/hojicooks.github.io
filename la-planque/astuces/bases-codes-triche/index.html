Codes de triche : seulement après la fin de l'histoire

AstuceBasesVérifié

Image : capture officielle © Rockstar Games · Vice City vue du ciel

Les codes reviennent, mais pas tout de suite. Le menu des codes n'apparaît qu'une fois l'histoire terminée, dans Menu Progression > Codes.

Ensuite, chaque code se débloque avec un défi : 100 séances de sport pour le gilet pare-balles, des médailles aux stands de tir pour les munitions, 50 magasins braqués à deux pour un filtre, etc. Quelques-uns (250 000 $, concentration infinie, météo) sont offerts dès la fin de l'histoire.

Pour entrer un code :

1. Sors le téléphone (HAUT sur la croix). 2. Maintiens L1 (LB sur Xbox) et appuie sur R1 (RB sur Xbox). 3. Tape la combinaison avec la croix directionnelle.

Un code pas encore débloqué ne fait rien. Et dès que tu en utilises un, la sauvegarde et les trophées/succès sont bloqués pour la session.

Il y a 61 codes en tout. Les combinaisons sont les mêmes sur PS5 et Xbox Series : seules les gâchettes changent de nom. Pour l'instant, 18 combinaisons sont connues : elles sont dans la rubrique Codes.
