# Cabine Miroir

Miroir selfie avec retardateur, dressing filtrable et essayage IA (démo gratuite IDM-VTON sur Hugging Face). Installable sur l'écran d'accueil.

Site : https://hojicooks.github.io

Les photos et le dressing restent dans le téléphone (stockage local du navigateur). Seul un essai IA envoie la photo choisie et le vêtement à la démo IDM-VTON.
